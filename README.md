# PA-4-CS-302
Project 4: Binary Search Tree 
Author: Isabella Delibassis
CS 302 Data Structures



The Data-file format is assumed to be writing each integer in the tree in preorder traversal, and inserting the values in order into an empty Binary Search Tree

Compile/run commands:

    To compile the code, you can type in "make" in the terminal

    To run the code, you can type in "./PA4" since the expository is named PA4

Assumptions:
    - If there is no minimum or maximum , then there will be a runtime_errror if it's an empty tree
